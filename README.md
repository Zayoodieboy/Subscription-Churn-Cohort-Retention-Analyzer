# 📉 Subscription Churn & Cohort Retention Analyzer

## 📌 Business Context & Problem Statement
* **Company:** SaaS & Subscription Box Service.
* **The Problem:** High initial customer acquisition costs mean nothing if users churn by Month 2 or Month 3. Stakeholders require clear visibility into cohort retention trends over time to identify drop-off points.
* **The Objective:** Programmatically initialize an SQLite database via Python, extract monthly usage activity using SQL queries, and transform raw metrics into a professional cohort retention heatmap matrix.

## 🛠️ Tech Stack & Tools
* **Database & Query Language:** Python (`sqlite3`), SQL (Date truncation functions `STRFTIME`, Relational Joins)
* **Data Manipulation & Analysis:** Python (`pandas`, `numpy`)
* **Data Visualization:** Python (`seaborn`, `matplotlib`)
* **Environment:** Jupyter Notebook (`.ipynb`)
* **Version Control:** Git & GitHub

## 📂 Repository Files
* `subscription_churn_analytics.ipynb`: Contains the complete end-to-end Python notebook with embedded SQL execution, cohort index math, and Seaborn heatmap generation.
* `subscription_churn_analytics.db`: The local SQLite database generated by the script containing user subscription and activity tables.

## 🏆 Results & Business Impact
By pivoting user activity into a normalized month-index matrix, this script visualizes exact percentage drop-offs per signup cohort. This allows retention teams to target intervention campaigns precisely at the months where churn spikes.
